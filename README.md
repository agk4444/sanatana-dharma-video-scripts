# Sanatana Dharma (1916) — Full-Book Video Scripts

Spoken narration scripts for the full-book video of *Sanatana Dharma: An Elementary
Text-book of Hindu Religion and Ethics* (Board of Trustees, Central Hindu College,
Benares, 1916) — all 24 chapters, summarised chapter by chapter.

- **Watch the video:** https://youtu.be/1XDU6xd6fhU (1h 35m, all 24 chapters)
- **Ask the book a question:** https://sanatana.socialnews.xyz
- **Read the 1916 text:** https://www.documentcloud.org/documents/28922146-sanatana-dharma-book/

## Files

- `sanatana-dharma-full-book-scripts.txt` — all 24 chapters in one document
  (12,380 words), 5 narration segments per chapter.
- `scripts/ch01/` … `scripts/ch24/` — the same scripts, one folder per chapter
  (`seg1.txt` … `seg5.txt` in each).
- `images/ch01/` … `images/ch24/` — the AI-generated images used in the video
  (96 images, segments 2–5 of each chapter; segment 1 is a title card, not an
  image). Warm sepia/amber painterly style, no text, no people.
- `chapters.txt` — the video's chapter timestamps (YouTube chapters).

## About the scripts

Each chapter is a ~4-minute spoken summary written from the chapter's own text —
the One Existence, the Many, re-birth, karma, sacrifice, the worlds, the
samskaras, worship, the four ashramas, the four castes, and the ethical
teachings. The narration is voiced in the video by an Indian voice ("Grounded
Cup"), over title cards and AI-generated images in the book's design.
